# 技術レポートの参考文献を Zotero に登録する

## このフォルダのファイル

| ファイル | 役割 |
|---|---|
| `build_zotero_manifest.py` | `../references.json`（参考文献の正本）から `manifest.json` を作る |
| `manifest.json` | 登録する文献の一覧（21件、本文あり2件） |
| `zotero_import_wafer_anomaly_monitoring.js` | Zotero に貼り付けて実行するスクリプト |
| `result.json` | 実行すると作られる結果（実行前はない） |

## スクリプトがすること

- まだ Zotero に無い文献を登録する（Import-ID・DOI・URL・題名のどれかが一致する項目があれば、新しく作らずに再利用する）
  - 本文を取得できた2件（Rasmussen & Williams 2006 の全文 PDF、Ledoit & Wolf の著者公開原稿）は、`../sources/` の PDF をコピーせずリンクで添付する
  - 本文を取得できなかった19件（有料論文・書籍）は書誌だけを登録し、「その他」欄に「本文未取得: 理由」を書く
  - 新しく作った項目にだけ「未読」タグを付け、テーマのコレクション（`01_半導体プロセス`・`02_フォトニクス・光学シミュレーション`・`03_機械学習`・`04_統計`）に入れる
- 案件のコレクション `2026-10-13_Wafer面内傾向の異常検知手法比較` を作り（1階層）、21件を入れる
- 既存の項目の中身・タグ・コレクションは消さない、書き換えない。何度実行しても二重に登録しない
- 以前の案件で使った文献（Noll 1976・Adel 2007・Pike 2012・Atkinson ほか 2007）は、以前のスクリプトを実行済みなら再利用される

## 実行手順

1. Zotero を起動する（起動済みならそのまま）
2. スクリプトをテキストエディタで開き、全選択してコピーする
3. Zotero のメニューで［ツール］→［開発］（表示によっては［開発者］）→［JavaScriptを実行］を開く
4. 開いた画面の「Run as async」にチェックを入れる（必須）
5. 左のコード欄に貼り付け（⌘V）、「Run」を押す
6. 右の結果欄の `summary` が「失敗 0 件」になれば完了。同じ内容が `result.json` にも保存される
7. 左のコレクション一覧に `2026-10-13_Wafer面内傾向の異常検知手法比較` ができ、21件が入っていることを確かめる

## 注意

- テーマのコレクションが見つからないときは何も登録せずに止まる（`result.json` の `failures` に名前が出る）
- 文献を追加・修正するときは `../references.json` を直し、`python3 build_zotero_manifest.py` で `manifest.json` を作り直してから実行する
- 本文 PDF（`../sources/`）は著作物なので Git に入れていない。別の PC で実行するときは `references.json` の `source_url` から取り直す
